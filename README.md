# Quiz de Python Interactivo

Este es un quiz interactivo sobre conceptos básicos de Python. El quiz incluye 10 preguntas que cubren temas fundamentales como:

- Tipos de datos
- Operadores
- Funciones básicas
- Métodos de listas
- Operaciones con strings
- Y más...

## Características

- Interfaz interactiva y amigable
- Retroalimentación inmediata
- Explicaciones detalladas para respuestas incorrectas
- Puntuación final
- Opción para reiniciar el quiz

## Cómo usar

1. Simplemente abre el siguiente enlace en tu navegador:
   [Quiz de Python](https://fabiflores2.github.io/quizjava/)

2. O si prefieres ejecutarlo localmente:
   - Descarga el repositorio
   - Abre el archivo `index.html` en tu navegador
